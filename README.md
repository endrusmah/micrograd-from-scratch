\# Neural Network from Scratch (Micrograd)



A simple neural network and automatic differentiation engine built from scratch using Python, inspired by Andrej Karpathy's micrograd.



\## Features



\- Scalar-valued automatic differentiation

\- Computation graphs and backpropagation

\- Neurons with tanh activation

\- Fully connected neural network layers

\- Multi-Layer Perceptron (MLP)

\- Gradient descent training

\- Optional computation graph visualization using Graphviz



\## Neural Network Architecture



The implemented neural network uses:



\- 3 input features

\- 2 hidden layers with 4 neurons each

\- 1 output neuron

\- 41 trainable parameters



\## Training



The network is trained using the sum of squared errors as the loss function and gradient descent to update its weights and biases.



\## Technologies



\- Python

\- Graphviz (optional, for visualization)



\## Purpose



This project was created to understand the fundamentals of neural networks, automatic differentiation, the chain rule, backpropagation, and gradient descent without relying on machine learning frameworks.
